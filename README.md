# GCR Cycle

Version DOI: https://doi.org/10.5281/zenodo.21752979

GCR Cycle is a method for converging generative AI outputs by repeatedly applying Generate, Compare, and Refine.

- Generate: Generate multiple outputs under the same conditions.
- Compare: Compare the outputs and identify commonalities and differences.
- Refine: Refine prompts or evaluation conditions based on the observed differences.

The purpose of GCR Cycle is not merely to improve output quality, but to reduce variation and improve reproducibility of generative AI outputs.


# GCRサイクル

GCRサイクルとは、生成AIの出力ばらつきを収束させるための反復手法である。

- Generate：同一条件で複数回生成する
- Compare：生成結果を比較し、共通点と差分を抽出する
- Refine：差分をもとにプロンプトや評価条件を精緻化する

本手法は、単なる品質向上ではなく、生成AI出力のばらつきを抑え、再現性を高めることを目的とする。
